# Lignum Harvester 0.1

Eigenständiger Harvester-Client im Lignum-System. Ziel ist, SilviA für Sortimentverwaltung und die Erzeugung der von TimberMatic 300 benötigten Apterierungsdaten zu ersetzen. TimberMatic bleibt zunächst für Maschinen-, Mess-, Vorschub- und Sägensteuerung verantwortlich.

## Phase 0.1
- Sortimentprofile mit Baumart, Sortiment, Längen und Durchmessergrenzen
- Offline-fähiges lokales Datenmodell
- Operator-Maske für aktiven Auftrag und Produktion
- TimberMatic-Adapter als klar getrennte Schnittstelle; zunächst Simulator
- Später: verifizierter APT-Export und Produktionsimport anhand echter Dateien des Harvesters

Keine aktive TimberMatic-Datei wird in 0.1 verändert.
